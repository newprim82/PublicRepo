# 📊 팀 지원 시간 & 업무량 분석 대시보드 (work-time-dashboard)

카카오톡 `[기술본부] 업무공유방`에 올라오는 작업 시작/완료 및 사후 보고 메시지를 자동으로 파싱하여, 팀원별 투입 공수(시간), 야간/주말 작업 비중, 고객사별 지원 시간 통계를 실시간으로 집계·시각화하는 모니터링 대시보드 시스템입니다.

---

## 🌟 주요 기능

1. **카카오톡 메시지 완벽 자동 파싱**:
   - **시작/완료 분리 보고**: `구분 / 담당자 / 고객사 / 상세 작업내용 / N시간 예정` ➔ 답장: `N시간 완료`
   - **사후 일괄 완료 보고**: `점검 / 김태현 / 국도화학 / 3분기 정기점검 / 2시간 완료(12시 시작)` ➔ 단일 메시지 즉시 `COMPLETED` 자동 인식
   - 발화자 프로필(`상상인 김시우 사원 / 기술 1팀`)에서 회사명, 이름, 직급, 소속팀 자동 분리
   - 심야(19시~08시 철야 작업) 및 주말 작업 자동 판별
2. **1시간 주기 백그라운드 자동 수집 & 실시간 즉시 긁어오기**:
   - 대시보드 실행 시 백그라운드 스레드에서 PC 카카오톡 `[기술본부] 업무공유방`을 1시간마다 무간섭(Read-Only) 자동 수집
   - 메인 상단 및 사이드바의 **`[⚡ 즉시 수집]`** 버튼으로 언제든 1초 만에 최신 대화 동기화
   - 다음 자동 수집까지 남은 시간(예: `⏳ 48분 뒤 자동수집`) 실시간 카운트다운 표출
3. **과중 근무(주 40h / 52h 초과) 실시간 감지 & 원클릭 보상 휴가 등록**:
   - 반짝반짝 빛나는 네온 배너 및 선명한 주황색(40h 초과) / 빨간색(52h 초과) 뱃지 버튼
   - 뱃지 클릭 시 즉시 해당 주차 상세 내역 및 보상 휴가 등록 모달 팝업 오픈
4. **팀원 직급 관리 & 드릴다운 인터랙티브 차트**:
   - 사원 / 대리 / 과장 / 수석 회사 표준 4대 직급 체계
   - 차트 바 클릭 시 팀원 전체 작업 목록 및 카테고리별 세부 팝업 연동
5. **독립 로컬 SQLite 고성능 데이터베이스 (`data/worklog.db`)**:
   - 별도 클라우드 설정 없이 2,000건 이상의 대용량 작업 로그를 초고속 처리

## 🚀 빠른 시작 가이드

### 웹 대시보드 실행
```bash
pip install -r requirements.txt
streamlit run src/dashboard/app.py
```
또는 `run_dashboard.bat`을 더블 클릭하여 실행합니다.

---

## 📁 프로젝트 구조

```
work-time-dashboard/
├── data/                    # 로컬 SQLite DB (worklog.db)
├── sample_data/             # 샘플 카카오톡 대화 데이터
├── src/
│   ├── analytics/           # KPI 및 통계 분석 모듈
│   ├── collector/           # 카카오톡 1시간 증분 자동 수집기
│   ├── dashboard/           # Streamlit 인터랙티브 웹 UI (app.py)
│   ├── database/            # 로컬 SQLite DB 매니저 (supabase_client.py)
│   ├── parser/              # 카카오톡 메시지 파싱 및 답장 매칭기
│   └── services/            # 팀/직급 관리 및 보상 휴가 서비스
├── requirements.txt         # 파이썬 의존성 패키지 목록
└── run_dashboard.bat        # 원클릭 실행 배치 파일
```
