## 🎯 4. 세부 판정 내역 및 비즈니스 로직 (Decision Rules)

### 4.1 09:00 정각 LIVE 관제 승격 정책 & 예정 일정 중복 배제 (v2.5.2)
- **정각 승격 원칙**: 기존 시작 30분 전 사전 승격 로직(`st_dt - 30분`)을 전면 폐지하고, 시작 시각 이전(`now < st_dt`)에는 무조건 하단 **"오늘 예정 일정 (SCHEDULED)"**에 대기합니다.
- **정각 도달 승격**: 현재 시각이 작업 시작 시각(**09:00 정각**)에 도달한 순간에만 상단 **"진행 중인 작업 (PENDING)"** 카드로 즉시 승격됩니다.
- **상하단 중복 원천 차단**:
  - 고객사명 정규화(`src/services/client_normalizer.py`: 예: 대구은행 ➔ IM뱅크)를 적용하여 표기 불일치로 인한 오탐을 방지합니다.
  - 카카오톡 시작 건과 아웃룩 예정 일정이 동일 작업자/고객사/시간대로 중복되는 경우, 상단에 진행 중 카드가 존재하면 하단 예정 일정 목록에서 자동 제외합니다.
  - `home_view.py`의 시작 전 작업 강제 재배치 및 상하단 배타성 안전망(Safety Guard)으로 동일 카드의 중복 노출을 100% 방지합니다.

### 4.2 출처(Source) 판정 및 화면 뱃지 표출 규칙
작업 데이터의 발생 경로에 따라 실시간 카드 및 완료 카드에 출처 뱃지가 부여됩니다:

| 출처 유형 | 판정 기준 | 전체 팀 뷰 (5열 좁은 화면) | 단일 팀 뷰 (4열 넓은 화면) | 뱃지 디자인 사양 |
| :--- | :--- | :---: | :---: | :--- |
| **카카오톡** | 카카오톡 업무공유방 파싱 데이터 | **`K`** | **`💬 카톡`** | `#FEE500` 노란색 배경, `#371d1e` 다크브라운 폰트, 볼드 |
| **아웃룩/Teams**| MS Outlook / Teams 캘린더 동기화 데이터 (`is_outlook=True`) | **`O`** | **`📅 아웃룩`** | `#0284c7` 블루 배경, `#ffffff` 화이트 폰트, 볼드 |
| **휴가/연차** | `is_leave=True` 또는 '휴가/연차/반차' 키워드 포함 건 | **`🏖️`** | **`🏖️ 휴가`** | `#f3e8ff` 연보라 배경, `#7e22ce` 보라 폰트 |

- **듀얼 뱃지 표출**: 동일 일정이 카톡과 아웃룩 양쪽에 모두 등록된 경우, DB 무결성을 위해 두 출처 데이터를 모두 보존하면서 카드에 **`[K][O]`(단일 팀: `[💬 카톡][📅 아웃룩]`) 듀얼 뱃지**를 동시 표출합니다.
- **화면 찌그러짐 방지**: 카드 폭 축소 시 텍스트 꺾임을 막기 위해 `white-space: nowrap`, `flex-shrink: 0` 속성을 모든 뱃지에 강제 적용합니다.

### 4.3 휴가/부재 카드 18:00 자동 전환 규칙
- **근무 시간대 (18:00 이전)**: 실시간 진행 영역 최상단 부재 배너에만 100% 카드로 표출 (오늘 완료된 작업 영역에는 중복 표출되지 않음).
- **퇴근 시간대 (18:00 이후)**: 실시간 상단 부재 영역에서 자동 숨김 처리되고, **"오늘 완료된 작업"** 영역으로 자연스럽게 이동하여 표출됩니다.

### 4.4 시간 상태 및 특수 근무 판정 규칙
1. **시작 시간 표기**:
   - 카톡 시작 건: **`시작보고 HH:MM`** (예: `시작보고 08:30`)
   - 아웃룩 일정 건: **`일정시작 HH:MM`** (예: `일정시작 09:00`)
2. **야간 작업 (`🌙 야간`) 판정**:
   - 작업 시작 시각이 **18:00 ~ 익일 06:00** 사이이거나 메시지에 `[야간]` 태그가 명시된 경우.
3. **주말 작업 (`🏖️ 주말`) 판정**:
   - 작업 일자가 **토요일(Saturday)**, **일요일(Sunday)** 또는 시스템에 등록된 **법정/임시 공휴일**인 경우.
4. **예정 시간 초과 (`⚠️ 초과`) 판정**:
   - `현재 시각(KST) - 작업 시작 시각 > 예정 시간(estimated_hours)` 인 경우 즉시 점등.
   - 프로그레스 바 100% 도달 후 붉은색 경고 점등 및 경과 시간 붉은색 볼드 처리.
5. **마우스 오버 툴팁 (Hover Tooltip)**:
   - 말줄임표(`...`) 처리된 긴 고객사명이나 작업 내용에 마우스를 올리면 `title` 속성으로 원문 전체 즉시 노출.

### 4.5 과중 근무 (주 40h / 52h) 2단계 알림 판정 규칙
- **법정 실근로시간 공제 원칙**: 카카오톡 `[교육]` 태그 건 및 `[휴가/연차]` 건은 일반 활동 통계에는 기록되나, **주 40h/52h 법정 근로시간 산정에서는 100% 자동 제외(공제)**됩니다.
- **1단계: 주 40h ~ 51.9h (주의)**: `⚠️ [근무 시간 경고]` 주황색 배너 및 `⚠️ 팀원명(주차:XX.Xh)` 주황색 버튼 칩 표출.
- **2단계: 주 52h 이상 (위험)**: `🚨 [과중 근무 발생 알림]` 붉은색 네온 사이렌 배너 및 `🚨 팀원명(주차:XX.Xh)` 강조 버튼 표출.
- **보상 휴가 연동**: 초과 근무에 대해 보상휴가가 승인된 건은 `✅ 보상 완료` 초록색 칩으로 전환.

### 4.6 페이지 전환 속도 최적화 & 사이드바 UI (v2.5.1 ~ v2.5.7)
- **필터 고속 캐싱 (`get_cached_filtered_data`)**: `@st.cache_data`를 적용하여 사용자가 메뉴를 전환할 때 이미 계산된 데이터프레임을 0ms로 즉시 반환합니다.
- **비데이터 화면 지연 연산 (Lazy Evaluation)**: 공휴일 관리, 계정 관리, 정기 메일 설정 등 `NON_DATA_PAGES`에 진입할 때는 대용량 데이터 필터링을 완전 건너뜁니다.
- **사이드바 UI 정돈 및 80px 스페이서 배치 (`v2.5.7`)**:
  - 미로그인 상태에서 인지 부하를 주던 `[게스트 모드]` 카드를 제거하고, 로그인 시에만 관리자 권한 카드를 노출합니다.
  - `🔑 관리자 로그인` 버튼이 뷰포트 크기에 구애받지 않고, **맨 아래 메뉴 기준 적절한 여백인 80px 아래(`sidebar-footer-spacer`)에 안정적으로 위치**하도록 정돈했습니다.
  - 중복 구분선(`border-top`)을 제거하여 미니멀하고 정갈한 사이드바를 유지합니다.

## 🧪 6. 단위 테스트 스위트 (Unit Test Suite)

본 시스템은 안정적인 프로덕션 운영을 위해 핵심 비즈니스 로직에 대해 **총 25개 단위 테스트**를 상시 유지합니다.

### 6.1 테스트 실행 방법
```bash
# 루트 또는 worktime_dashboard 디렉토리에서 실행
python -m unittest discover worktime_dashboard/tests
```

### 6.2 테스트 커버리지 영역
1. **인증 및 보안 (`test_auth_manager.py`, 4건)**: 비밀번호 해싱 검증, 로그인 성공/실패 처리, 브루트포스 5회 실패 시 5분 계정 잠금 가드.
2. **고객사 정규화 (`test_client_normalizer.py`, 4건)**: 금융권 명칭(대구은행 ➔ IM뱅크 등), 법인격 표기 제거, 공백 표준화.
3. **데이터 필터 캐싱 (`test_data_filter_cache.py`, 5건)**: `get_cached_filtered_data()` 팀/월/직급/야간 필터링 정확도 및 빈 데이터 안전성.
4. **메시지 파싱 (`test_kakao_parser.py`, 5건)**: 단발성/다일 작업 파싱, 시간 단위 정규화, 다중 작업자 분할.
5. **야간/주말 판정 (`test_night_weekend.py`, 4건)**: 18시 이후 야간 작업 분류, 공휴일/주말 근무 판정.
6. **일정 동기화 & 정각 승격 (`test_schedule_sync.py`, 3건)**: 09:00 이전 예정 일정 유지, 09:00 정각 LIVE 승격, 카톡-아웃룩 중복 제거.
