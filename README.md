# PublicRepo

공용 프로젝트 모노레포(Monorepo) 저장소입니다.

## 📁 프로젝트 목록

### 📊 [worktime_dashboard](./worktime_dashboard)
- **팀 현장 지원 시간 및 업무량 분석 대시보드 (Cisco ACI 관제 테마)**
- 카카오톡 실시간 업무 보고 및 Outlook 캘린더 일정을 자동 연동/분석하는 웹 관제 포털 시스템
- **주요 기능**: 실시간 현장 관제, 작업 집계, 휴가/근태 연동, 40h/52h 근무 시간 모니터링, 주간 자동 리포트 메일 발송

#### 🚀 실행 방법
- **대시보드 업데이트 및 실행**: `update_and_run.bat` 실행 (또는 `worktime_dashboard/update_and_run.bat`)
- **대시보드 단독 실행**: `run_dashboard.bat` 실행
- **수집기 단독 실행**: `run_collector.bat` 실행
