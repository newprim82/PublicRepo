- **아웃룩 삭제 일정 자동 동기화 구현**:
  - 아웃룩 수집 범위(동기화 대상 기간 및 대상 작업자) 내에서 사용자가 아웃룩 일정을 삭제했을 때, DB(로컬 SQLite 및 Supabase Cloud)에서도 이를 감지하여 자동 삭제(cleanup)하는 3중 안전 가드 동기화 로직 구현 (`56de50b`).
- **라이브 관제 3단 구조 개편 (진행 중 / 예정 / 완료)**:
  - 아웃룩 당일 미착수 일정(시작 30분 전 이전)을 `SCHEDULED`(오늘 예정 일정)으로 자동 수집 및 승격.
  - 라이브 관제 섹션을 `진행 중인 작업 (PENDING)` / `오늘 예정 일정 (SCHEDULED)` / `오늘 완료된 작업 (COMPLETED)`의 명확한 3단 구조로 재구성.
  - 상단 요약 바에 `📅 예정: N건` 추가 및 예정 전용 카드 디자인(남은 시간 카운트다운/시작 대기 뱃지) 구현.
- **휴가 카드 18:00 자동 전환 규칙 적용**:
  - 근무 시간대(18:00 이전): 실시간 진행 영역 최상단 부재 배너에만 100% 카드로 표출 (오늘 완료된 작업 영역에는 표출되지 않음).
  - 퇴근 시간대(18:00 이후): 실시간 상단 부재 영역에서 자동 숨김 처리되고, `오늘 완료된 작업` 영역으로 자연스럽게 이동하여 표출 (`731f103`).
- **예정 일정 카드 UI 실시간 카드와 완벽 통일**:
  - 카드 생김새, 중간 바 규격, 상단 우측 `시작예정 {시간}` 뱃지 레이아웃 통일.
  - 카톡/아웃룩 출처 뱃지를 하단 좌측(`⏱️ 예정 X.Xh` 앞)으로 재배치.
  - 단일 팀 뷰에서 `O`/`K` 단축형 대신 `📅 아웃룩`/`💬 카톡` 풀 텍스트 뱃지 정확히 적용.
  - 섹션 헤더 연동 뱃지 역시 단일 팀 기준 `📅 아웃룩`으로 통일.
  - `APP_VERSION`을 `v2.2.17`로 갱신.
